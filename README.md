# Gravity Sandbox

Интерактивная песочница гравитирующих точек в браузере. Ньютоновское притяжение,
два взаимозаменяемых рендерера (Canvas 2D и raw WebGL), без сборки, зависимостей и сервера.

## Запуск

Откройте `index.html` двойным щелчком (работает через `file://`) в Chrome или Safari.
Сервер не нужен: никаких ES-модулей и `fetch` — только классические `<script>` и общий
namespace `window.GS`.

## Запуск как Telegram Mini App

Приложение статическое, поэтому достаточно выложить папку целиком на любой HTTPS-хостинг
(GitHub Pages, Netlify, Vercel, Cloudflare Pages) и указать этот URL в BotFather:

1. `python3 -m http.server 8000` + `cloudflared tunnel --url http://localhost:8000` — для локальной отладки;
2. BotFather: `/newapp` → выбрать бота → задать **Web App URL**; `/setmenubutton` — кнопка «Меню»;
3. прямая ссылка: `https://t.me/<bot>/<appname>`.

Требования к хостингу: HTTPS, `index.html` по корню, без авторизации и без `X-Frame-Options`.

Что уже сделано под webview:

- подключён `telegram-web-app.js`; в `js/main.js` вызываются `ready()`, `expand()`,
  `disableVerticalSwipes()`, `setHeaderColor`/`setBackgroundColor`, `enableClosingConfirmation()`;
- `viewportChanged` / `safeAreaChanged` пересчитывают высоту (`--tg-viewport-stable-height`)
  и канвас — без этого панель «прыгает» при появлении шапки Telegram;
- ввод переведён на Pointer Events (`pointerdown/move/up/cancel`, `setPointerCapture`),
  так что кисть, `launch` и `drag` работают и мышью, и пальцем; активный указатель один,
  второй палец игнорируется;
- медиазапрос `max-width: 720px` превращает панель в оверлей; она стартует свёрнутой,
  закрывается тапом мимо, а вернуть её можно кнопкой `#panel-fab` в левом верхнем углу;
- кнопка `#panel-fab` показывается при любой свёрнутой панели — и на мобильном, и на десктопе;
- учтены `env(safe-area-inset-*)` (вырез, нижняя полоса) и `touch-action: none` на канвасе.

Если WebGL в webview недоступен, `main.js` сам переключается на Canvas 2D (см. «Рендереры»).


## Управление

- **Пуск / Пауза** — останавливает и возобновляет симуляцию. **Шаг** — один шаг `dt`.
  **Сброс** — перезагрузка выбранного пресета.
- **Пресет** — «Солнечная система», «Двойная звезда», «Хаос / скопление», «Пусто».
- **Кисть** — масса (лог-слайдер 0.1…100), радиус (авто из массы `∝ ∛m` или вручную),
  цвет, флаг «чёрная дыра».
- **Режимы указателя:**
  - `add` — тап/клик создаёт точку с текущими настройками;
  - `launch` — нажмите, протяните вектор и отпустите: точка создаётся с начальной
    скоростью, пропорциональной длине протяжки;
  - `drag` — перетаскивание существующей точки (на время переноса её скорость обнуляется).
- Колесо мыши меняет массу кисти (вид фиксирован, зум не используется). На тач-экранах
  указатель-«призрак» не рисуется.

## Панель «Мир»

- **G** — гравитационная постоянная; **Скорость** — множитель времени; **Softening ε** —
  сглаживание против сингулярностей в законе `F = G·m₁·m₂ / (r² + ε²)`.
- **Слияния при столкновении** — при `r < r₁+r₂` тела сливаются с сохранением массы,
  импульса и центра масс; цвет берётся у более массивного; радиус пересчитывается `∝ ∛m`.
- **Трейлы**, **векторы скорости**, **векторы ускорения**, **свечение** (последнее — только
  для Canvas 2D; по умолчанию выключено = «минимализм»).

## Рендереры

- **Canvas 2D** — точки заливкой цветом; при включённых трейлах фон перекрывается
  полупрозрачно (`rgba(bg, 0.15)`), создавая затухающий след. Опциональное свечение —
  радиальный градиент.
- **WebGL** — raw WebGL 1.0: point sprites (`gl_PointCoord` + `discard` для круглой маски),
  динамический VBO, ортографическая проекция world→NDC, линии для векторов и рамки мира,
  трейлы через FBO ping-pong с alpha-затуханием. Если контекст недоступен — предупреждение
  и автоматическое переключение на Canvas 2D.

Переключатель сохраняет сцену: при смене бэкенда canvas заменяется (элемент может держать
лишь один тип контекста), сцена и вид остаются нетронутыми.

## Мир и физика

- Мир — условные единицы `1000×1000`, `G ≈ 1`, массы `1…100` (центральные тела тяжелее).
- Камера фиксированная с сохранением пропорций (letterbox); выход за край заворачивает
  координаты (**wrap**, тороидальный мир). Гравитация считается только по прямому
  расстоянию, без minimum-image через границу.
- Ускорения — двойной цикл O(n²) с softening; интегратор — **полу-неявный Эйлер**;
  фиксированный `dt = 1/120` с аккумулятором реального времени и ограничением суб-шагов
  (не более 8 за кадр, излишек отбрасывается, чтобы не «догонять» бесконечно).

## Сцена

- **Save JSON** — скачивает текущую сцену (тела, параметры мира и настройки отображения).
- **Load JSON** — восстанавливает сцену из файла (`<input type=file>` + `FileReader`).
- **Очистить** — удаляет все тела, оставляя параметры мира.

## Инфо

FPS, число тел, суммарная кинетическая и потенциальная энергия (условные единицы),
суб-шагов за последний кадр.

## Структура

```
index.html          разметка панели и <canvas>, порядок подключения скриптов
style.css           тёмная тема, layout панели и сцены
js/core.js          утилиты, ГПСЧ, модель Body, Scene, сериализация
js/physics.js       ускорения, интеграция, wrap, слияния
js/presets.js       4 фабрики сцен
js/render2d.js      Canvas 2D-рендерер
js/renderwebgl.js   raw WebGL-рендерер (VBO, point sprites, FBO-трейлы)
js/ui.js            панель, ввод (pointer-события), save/load, метрики
js/main.js          цикл requestAnimationFrame, фикс. dt, выбор рендерера
```

Порядок подключения обязателен: `core → physics → presets → render2d → renderwebgl → ui → main`.
Каждый файл расширяет `window.GS`.

## Ограничения

- O(n²) физика ограничивает число тел несколькими тысячами независимо от рендерера; при
  больших сценах узкое место — физика, а не отрисовка (Barnes–Hut вне текущего объёма).
- Полу-неявный Эйлер слабее держит энергию на орбитах, чем Verlet (осознанный выбор);
  при `dt = 1/120` визуально приемлемо.
- Тема фиксированная тёмная.
